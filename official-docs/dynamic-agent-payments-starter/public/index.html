Agents

Create agent

Registers a new agent and creates/assigns its wallet in one step.

No developer token, no human. Instead, each agent proves who it is with its own private key — Dynamic calls this an agent signing token. It works like a person signing a login message with their crypto wallet, except the agent holds the key and signs itself in, with no human involved. Whoever holds that key is that Dynamic user — a new agent here generates a brand-new key, making it a brand-new Dynamic user with its own wallet.
